# M.A.I. Memory

This file stores accumulated context from agent loops.
The agent reads this at the start of each interaction to maintain continuity.

## How It Works

- The `compact-memory` action can summarize this file to keep it manageable
- New observations, decisions, and context are added by the agent
- This file is read automatically as part of the context payload
